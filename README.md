# Kunal Kumar Portfolio

Static portfolio website for GitHub Pages.

Animations use GSAP and ScrollTrigger from jsDelivr, with a no-build static fallback.

## Local Preview

Open `index.html` directly in a browser, or serve the folder with any static file server.

## GitHub Pages

Use the repository Pages settings:

1. Source: `Deploy from a branch`
2. Branch: `main`
3. Folder: `/root`

The site should publish at:

```text
https://kunalkumar007.github.io/my-resume/
```

Update the LinkedIn and Blogs links in `index.html` once the final URLs are available.
